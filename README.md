# Horace-Englossed
Interactive digital edition of Horace's carmen 1,12.

## Project Overview
This project is focused on creating an engaging platform for users to explore the glosses (containing a commentary by Acronius) alongside the poem as viewed in the manuscript.

## Features
- toggle view for
    - glosses
    - translation
    - expanded abbreviations    
- manuscript pages
- TEI code
- tooltip for glossary
