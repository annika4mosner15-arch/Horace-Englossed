# Horace-Englossed
Interactive digital edition of Horace's carmen 1,12.

## Project Overview
This project is focused on creating an engaging platform for users to explore the glosses alongside the poem as viewed in the manuscript.

## Features
- glosses toggle view
- manuscript pages
- TEI code
